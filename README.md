# 🎲 랜덤 뽑기 (random_race)

참가자 이름을 입력하고 게임을 골라 당첨자를 뽑는 웹 페이지입니다. 설치 없이 브라우저에서 바로 실행됩니다.

- 🏎️ **랜덤 그랑프리** — 3D 카트 레이스(자유 주행): 구불구불·급커브·언덕, 아이템·망치·기둥, 역전 드라마
- 🔮 **랜덤 구슬 레이스** — 위에서 아래로 떨어지는 구슬: 풍차·범퍼·무너지는 막대로 순서가 뒤바뀜
- 🛣️ **레인 달리기** — 레인별로 나란히 달리는 3D 레이스 (20명 이하)

최대 100명, 코스 길이와 당첨 인원 선택 가능. 효과음·배경 리듬은 브라우저에서 합성합니다(별도 음원 없음).

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 게임 선택 화면 (이름·코스 길이·당첨 인원 입력) |
| `random-race-3d.html` | 랜덤 그랑프리 / 레인 달리기 (three.js) |
| `random-marble.html` | 랜덤 구슬 레이스 (Matter.js) |
| `sfx.js` | 공용 효과음·배경 리듬 |

three.js, Matter.js는 CDN(cdnjs)에서 불러오므로 인터넷 연결이 필요합니다. 입력한 이름은 서버로 전송되지 않고 브라우저(localStorage)에만 저장됩니다.
